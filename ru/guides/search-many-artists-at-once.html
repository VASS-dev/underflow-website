Поиск по десяти артистам сразу: пакетный диггинг для диджеев

Поиск по одному артисту в пяти магазинах умножает одни и те же шаги. Пакет превращает вечер поисков в один список, который можно просмотреть.

1. Сначала подготовьте список

Выпишите десять артистов: трёх, которых играете постоянно, четырёх из любимых сцен и трёх, о которых говорят друзья. Готовый список не даёт разбрестись.

2. Ищите их вместе

В Underflow отметьте артистов и нажмите Mass search. Их треки из Bandcamp, Beatport, Decks.de, Juno Records и Discogs придут одним списком, до 10 артистов за раз.

3. Первый скан занимает больше времени

Новый артист при первом сканировании обрабатывается дольше. Повторные поиски быстрые, поэтому запускайте новые имена пачкой и занимайтесь другим, пока идёт поиск.

4. Просматривайте по магазину и по дате

Фильтруйте общий список по магазину, когда хотите купить в конкретном месте, и по диапазону дат, когда нужны только новинки с прошлого раза.

5. Превращайте результаты в следующие зёрна

Связанные артисты из пакета дают следующие десять имён. Повторите раз-другой, и список растёт сам.

Ищите по всем магазинам сразу

Underflow выполняет один пакетный поиск по 10 артистам в пяти магазинах и показывает всё одним списком. Бесплатно на время открытой беты.
