How to export a list of tracks to CSV and open it in Excel

A list of tracks you can sort, filter and share beats a pile of browser tabs. A CSV file is the simplest way to take that list out of any app.

1. Filter first, export second

Export what you want to keep, not the whole library. Narrow the list by store, date range or tags, so the file holds one purchase round or one set idea.

2. Know what the file should contain

Useful columns are artist, title, label, release date, when you added the track and where it stands: wishlist, buy list, downloaded, listened. In Underflow the export button in the toolbar saves exactly these columns for the tracks currently in the list.

3. Open it in Excel without broken characters

The Underflow file is UTF-8 with a semicolon between columns, which Excel opens correctly in many regional settings. If everything lands in one column, use Data, From Text/CSV and choose the semicolon as the delimiter.

4. Use the sheet for what apps do badly

Sort by label to plan a label-by-label purchase, filter the buy list by date, or send the list to a friend or a record store. A spreadsheet also works as a backup of your picks.

5. Re-export when the list changes

Treat the file as a snapshot. After a new digging session, filter again and export again instead of editing the old file by hand.
